# Campus Marketplace

The students can list their old items which they don't need any more in this site so others can buy them.

## Features
> [!NOTE]
> new features will roll out
- Login and registration with college email and password
- Protected dashboard, settings, and marketplace routes
- Browse listings with category filtering and search
- Create, archive, favorite, and book marketplace listings
- Profile settings with optimized avatar uploads
- Booking orders with seller confirmation or decline
- Initial direct messaging workflow

### Tech Stack

- **React + Vite**
- **javascript**
- **Supabase (postgreSQL, realtime, auth, edgefunction)**
